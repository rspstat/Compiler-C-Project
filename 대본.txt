Cute Compiler 프로젝트 발표 대본 (4분)
인트로 (30초)
안녕하세요! 오늘은 제가 개발한 **"Cute Compiler"**를 소개해드리겠습니다.
요즘 한국 사회가 너무 날카롭다고 느껴져서, 프로그래밍 언어라도 둥글둥글하게 만들어보자는 아이디어로 시작했습니다. "고마웡", "요기부터", "저장할랭" 같은 귀여운 한국어 표현으로 코딩할 수 있는 컴파일러를 만들었습니다.
프로젝트 개요 (45초)
Cute Compiler의 주요 특징을 보여드리겠습니다.
[화면: C언어와 Cute언어 비교표 보여주기]
기존 C언어에서는 if (x > y) { temp = x; }라고 쓰던 것을
Cute언어에서는 만약에 x가 y보다 크다면 요기부터 temp에 x를 저장할랭 요기까지 실행할랭으로 쓸 수 있습니다.
영어 중심의 프로그래밍 환경에서 벗어나 모국어로 코딩할 수 있어 초보자들의 진입장벽을 낮췄습니다.
컴파일러 구조 (1분)
[화면: 컴파일러 구조도 보여주기]
컴파일러는 크게 5단계로 구성됩니다:

어휘분석기(cute.l): "저장할랭" → SAVE 토큰으로 변환
구문분석기(cute.y): 토큰들을 문법 규칙에 따라 AST로 구성
의미분석기: 타입 체크와 스코프 검사
코드생성기: 스택 기반 어셈블리 코드 생성
심볼테이블: 변수와 함수명 관리

특히 한국어 문법을 BNF 형태로 표현하는 것이 가장 큰 도전이었습니다.
주요 기능 시연 (1분 30초)
실제 구현된 기능들을 보여드리겠습니다.
[화면: 코드 실행 화면들 순서대로 보여주기]
1. 산술연산과 조건문
만약에 x가 5보다 크다면 요기부터
  x에 100을 저장할랭
요기까지 실행할랭
실행결과: 정상적으로 조건문이 동작합니다.
2. 반복문 (While, For)
counter가 5보다 작다면 요기부터
  result *= 2
  counter++
요기까지 반복할랭
3. 특별한 기능들

Swap: x와 y의 값을 서로 바꿔줭 - 한 줄로 두 변수 교환
삼항연산자: max에 a가 b보다 크다면 a를 저장할랭 아니라면 b를 저장할랭
함수: 함수이름은 func_a이고... 형태로 자연스러운 한국어 문법 사용

기술적 도전과 해결 (45초)
[화면: 코드 구조 보여주기]
가장 어려웠던 부분들과 해결책:

중첩 구조 처리: If문, While문 등이 중첩될 때 라벨 충돌 방지
→ count_if_nodes() 함수로 내부 노드 개수를 계산해 라벨 오프셋 조정
루프 라벨 배치: While, For문에서 시작점 라벨 배치 위치 문제
→ wloop_end, floop_end 같은 추가 노드 도입으로 해결
DFS 순회와 코드 생성: 후위 순회로 올바른 실행 순서 보장

성과와 결론 (30초)
[화면: 실행 결과들 종합]
총 8가지 주요 기능을 성공적으로 구현했습니다:

산술연산, if-else, while, for, 삼항연산자, 함수, switch, swap

이 프로젝트를 통해 컴파일러의 전체적인 동작 원리를 깊이 이해할 수 있었고, 무엇보다 '둥글둥글한 프로그래밍'이라는 새로운 패러다임을 제시했다고 생각합니다.
한 명이라도 이 귀여운 언어로 프로그래밍에 친숙해진다면, 이 프로젝트는 충분히 성공적이라고 할 수 있겠습니다.
