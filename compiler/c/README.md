# Extended C Compiler for Stack Machine

## 프로젝트 개요

이 프로젝트는 C 언어의 부분집합을 컴파일하여 스택 머신 코드를 생성하는 컴파일러입니다. Lex(flex)와 Yacc(bison)을 사용하여 구현되었으며, StackSim과 호환되는 스택 머신 코드를 생성합니다.

## 주요 특징

### 지원하는 언어 기능

1. **기본 데이터 타입**
   - `int`, `float`, `char`, `void`
   - 배열 선언 및 사용
   - 문자열 및 문자 리터럴

2. **연산자**
   - 산술 연산자: `+`, `-`, `*`, `/`, `%`
   - 비교 연산자: `==`, `!=`, `<`, `>`, `<=`, `>=`
   - 논리 연산자: `&&`, `||`, `!`
   - 비트 연산자: `&`, `|`, `^`, `~`, `<<`, `>>`
   - 대입 연산자: `=`, `+=`, `-=`, `*=`, `/=`, `%=`
   - 증감 연산자: `++`, `--` (전위/후위)
   - 삼항 연산자: `? :`

3. **제어 구조**
   - 조건문: `if`, `if-else`
   - 반복문: `while`, `for`, `do-while`
   - 분기문: `switch-case-default`
   - 점프문: `break`, `continue`, `return`

4. **함수**
   - 함수 정의 및 호출
   - 매개변수 전달
   - 재귀 함수 지원

5. **입출력**
   - `print()`: 값 출력
   - `read()`: 값 입력

6. **고급 기능**
   - `sizeof` 연산자
   - 배열 인덱싱
   - 중첩 구조 지원
   - 복잡한 표현식 처리

### 생성되는 스택 머신 명령어

- **데이터 조작**: `LIT`, `LOD`, `STO`
- **산술 연산**: `ADD`, `SUB`, `MUL`, `DIV`, `MOD`, `NEG`
- **논리 연산**: `AND`, `OR`, `NOT`
- **비트 연산**: `BNOT`, `SHL`, `SHR`
- **비교 연산**: `EQ`, `NE`, `LT`, `GT`, `LE`, `GE`
- **제어 흐름**: `JMP`, `JEQ`, `JNE`
- **함수 관련**: `CALL`, `RET`
- **입출력**: `PRINT`, `READ`
- **기타**: `HALT`, `LOAD`

## 빌드 및 실행

### 필요 도구
- gcc (C 컴파일러)
- flex (Lexical Analyzer Generator)
- bison (Parser Generator)
- make

### 빌드 방법

```bash
# 전체 빌드
make

# 또는 개별 단계
make clean          # 이전 빌드 파일 삭제
make cbc           # 컴파일러 빌드
```

### 사용 방법

```bash
# C 소스 파일을 스택 머신 코드로 컴파일
./cbc input.cbc > output.stk

# 또는 파일 출력 없이 직접 확인
./cbc input.cbc
```

### 테스트 실행

```bash
# 모든 테스트 실행
make test

# 개별 테스트 실행
make test1    # 기본 산술 연산
make test2    # 제어 구조
make test3    # 배열과 복잡한 연산
make test4    # 함수와 고급 기능
make test5    # 입출력과 고급 제어
```

## 확장 기능

### 1. 언어 설계 확장
- **향상된 연산자 집합**: 전통적인 C 연산자 외에 비트 시프트, 복합 대입 연산자 추가
- **다양한 제어 구조**: switch-case, do-while 등 추가 제어 구조 지원
- **배열 지원**: 1차원 배열의 완전한 지원
- **함수 시스템**: 매개변수, 반환값, 재귀 호출 지원

### 2. 새 명령어 구현
- **비트 연산**: BNOT, SHL, SHR 명령어 추가
- **고급 비교**: LE, GE 명령어로 <= >= 연산 지원
- **입출력 명령어**: PRINT, READ 명령어로 간단한 I/O 지원
- **배열 접근**: LOAD 명령어로 배열 인덱싱 지원

### 3. 실용적 기능
- **심볼 테이블**: 변수 관리 및 스코프 처리
- **타입 시스템**: 기본 데이터 타입 지원
- **오류 처리**: 구문 오류 및 의미 오류 검출
- **코드 최적화**: 불필요한 명령어 제거

### 4. 독창적 요소
- **확장 가능한 아키텍처**: 새로운 연산자와 문법 구조를 쉽게 추가할 수 있는 설계
- **풍부한 테스트 케이스**: 다양한 프로그래밍 패턴을 검증하는 포괄적인 테스트
- **실용적인 예제**: 실제 알고리즘(정렬, 수학 함수 등)을 구현하는 테스트

## 스택 머신 코드 예제

입력 C 코드:
```c
int main() {
    int a = 10;
    int b = 20;
    int c = a + b;
    print(c);
    return 0;
}
```

생성되는 스택 머신 코드:
```
LIT 10
STO 0
LIT 20
STO 1
LOD 0
LOD 1
ADD
STO 2
LOD 2
PRINT
RET
HALT
```

## 주의사항

1. **메모리 관리**: 현재 구현은 간단한 메모리 모델을 사용합니다.
2. **타입 검사**: 기본적인 타입 검사만 수행됩니다.
3. **스코프**: 전역 스코프만 지원됩니다.
4. **라이브러리**: 표준 라이브러리 함수는 지원하지 않습니다.
