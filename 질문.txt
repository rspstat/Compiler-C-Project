과제 내용: 작은 규모의 C 언어 컴파일러를 작성하시오. Lex (flex)와 Yacc (bison)을 이용하여 구현하고 코드 생성은 stack machine용 코드로 하시오. 컴파일러 검증을 위한 도구로 StackSim (Stack Machine Simulator: StackSim.exe)가 제공되며, 또한 예제 컴파일러 cbc의 소스를 제공하므로 이를 기반으로 확장 및 변형하여 컴파일러를 작성하시오. 평가 기준: 언어 설계 확장 및 새 명령어 구현의 종류, 완성도, 실용성, 독창성 등 (명령어 추가 구현 예: 다양한 연산, 분기문, 중첩문, 함수 등) 제출 내용: 프로그램 소스 및 테스트 샘플 소스 (*.l, *.y, *.cbc).



compiler.l, compiler.y, test1~.cbc 파일을 전부 작성하시오.



1. 이 파일들은 compiler.h, compiler.c, compilerlex.c 로 도출될 것이다.

2. 한글로 대답하여라.

3. 주석은 전부 제거하여라.

4. 너에게 과제 요구사항에 언급된 예제 컴파일러 cbc의 소스를 제공한다.



sample.cbc:

main() 

{

	매출액 =  100;

	매출원가 = 50;

	관리비 = 10;

	판매비 = 20;

	비용 = 매출원가 + 관리비 + 판매비;

	profit = 매출액 - 비용;

}
