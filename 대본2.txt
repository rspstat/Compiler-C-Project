### 0:45 – 1:25 │ 언어 설계

* (슬라이드 2: C ↔ Cute 대응표)

  > “‘+’는 *더하기*, ‘if’는 *만약에*, 중괄호는 *요기부터\~요기까지*로 바꿨습니다.”&#x20;
* (예시 코드 짧게 보여주기)

  ```cute
  시작할랭
      x에 10을 저장할랭
      만약에 x가 5보다 크다면 요기부터
          x에 100을 저장할랭
      요기까지 실행할랭
  고마웡
  ```

### 1:25 – 2:05 │ 컴파일러 구조

* (슬라이드 3: 4-단계 파이프라인)

  1. **Lex** – 한국어 토큰 인식 (*cute.l*)
  2. **Yacc** – BNF 문법으로 AST 생성 (*cute.y*)
  3. **DFS 코드 생성** – 스택 기반 어셈블리
  4. **Stacks SIM 실행** – 결과 확인&#x20;
* (트리 그림 + 스택 코드 한 줄)

  > “예를 들어 `만약에` 조건은 DFS를 돌며 `IFLABEL`을 자동 발급해 분기 코드를 만듭니다.”&#x20;

---

### 2:05 – 3:20 │ 라이브 시연

*(캡처 혹은 녹화 화면으로 진행)*

1. **컴파일 단계**

   ```bash
   flex cute.l
   bison -d cute.y
   gcc lex.yy.c cute.tab.c -o cutecc
   ```

   > “오류 없이 빌드되면 실행 파일 *cutecc*가 생성됩니다.”

2. **소스 실행**

   ```bash
   ./cutecc < sample.cute > sample.asm
   stacksim sample.asm
   ```

   * (터미널에 어셈블리 일부 확대)

   > “여기 `LVALUE x`, `PUSH 10`, `:=` … Cute 코드가 스택 명령으로 변환된 모습입니다.”&#x20;

3. **동작 확인**

   * (if-else, while, swap, printf 예시 차례로 출력)

   > “`counter`가 0→4까지 증가하며 `result` 값이 찍히고, `swap` 문은 임시 변수 *TEMP*를 자동 생성해 두 값을 교환합니다.”&#x20;

---

### 3:20 – 4:00 │ 핵심 기능 하이라이트

* **스페셜 문법**

  | 기능     | 한 줄 설명                  |
  | ------ | ----------------------- |
  | `swap` | 임시 변수 자동 생성으로 값 교환      |
  | 삼항연산자  | 조건에 따라 변수 선택 저장         |
  | 사용자 함수 | `함수이름은 … 선언할랭` / `호출할랭` |
* (라벨·심볼테이블 스냅샷)

  > “라벨 충돌을 막기 위해 `count_if_nodes`처럼 중첩 수를 세어 오프셋을 계산했습니다.”&#x20;
